# Banking Console App

Console banking application written in C#.

## Features

- User registration
- User login/logout
- Create bank account
- Show accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Transaction history

## Technologies

- C#
- .NET
- Object-Oriented Programming
- Console Application

## Project structure

- Program.cs
- AuthService.cs
- BankService.cs
- User.cs
- BankAccount.cs
- Transaction.cs

## Purpose

This project was created as a portfolio project for learning C# and preparing for junior developer roles in banking.
